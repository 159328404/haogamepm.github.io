# Hao的游戏PM工作空间

这是一个用于管理游戏项目管理相关内容的GitHub仓库，包含：

## 文件夹结构

- **会议纪要**：会议纪要整理相关的内容
- **每日工作总结**：Hao的个人风格工作总结
- **游戏PM文章**：游戏PM相关的自媒体文章
- **课程内容**：课程制作相关的内容（第1-15章）
- **播客内容**：油管解读播客相关的内容
- **配置备份**：Claude配置和技能备份
- **技能配置**：所有Claude Skill的定义文件和参考资料

## 技能配置

本仓库包含以下Claude Skill的完整定义：

1. **会议纪要整理**：游戏项目会议纪要结构化整理
2. **每日工作总结**：Hao个人风格的工作总结生成
3. **游戏PM文章**：游戏PM自媒体文章创作
4. **课程制作**：游戏项目管理课程制作
5. **油管解读播客**：YouTube视频转中文精读播客

## 使用说明

1. 克隆仓库到本地：`git clone git@github.com:159328404/haogamepm.github.io.git`
2. 在Cursor中打开项目文件夹
3. 进行编辑和修改
4. 提交更改：`git add .` → `git commit -m "描述"` → `git push`

## 注意事项

- 请勿提交敏感信息（如API密钥、密码等）
- 大文件请使用Git LFS或外部存储
- 定期提交和推送，保持多设备同步
