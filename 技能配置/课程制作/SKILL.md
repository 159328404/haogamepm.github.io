# Hao的课程制作技能

## 课程体系定位

Hao的课程产品线：
- **入门课**（698元）：14讲，面向0-1年新人，B站/小红书视频
- **进阶课**（1298-1998元）：34章，面向1-3年PM，文字+录屏+社群
- **垂直课**（定价灵活）：如美术管理、AI+PM，针对特定领域

## 内容风格规范

### 文案调性
- 真实直白，不讲空话
- 用对话和会议场景还原真实项目
- 给具体的字段示范、流程图思路
- 偶尔带点轻松吐槽，不端着
- 用"你"来写痛点，增强代入感

### 叙事结构
痛点场景 → 问题本质 → 解决框架 → 实操细节 → 案例验证

### 禁止内容
- 具体公司名（用"某二次元项目"代替）
- 具体项目代号（用"我负责的修仙品类项目"代替）
- 未脱敏的数据（用比例或范围代替具体数字）

## 案例格式规范

所有案例必须包含五个部分：

**案例：[案例标题]**

**背景**
[项目类型、团队规模、所处阶段，2-3句话]

**问题**
[遇到了什么问题，问题的表现是什么，2-3句话]

**处理方式**
[采取了什么行动，分步骤描述，3-5个要点]

**结果**
[产生了什么效果，用相对数据或定性描述]

**复盘**
[这个案例的关键启示是什么，可复用的经验是什么]

## 输出格式指南

### 1. 课程大纲
输出完整的模块-章节结构，包含：
- 模块名称和定位
- 各章节标题
- 预计时长
- 核心交付物清单

### 2. 章节内容（文字版）
按章节级结构模板输出，确保：
- 每章3000-5000字
- 包含至少1个完整案例
- 列出本章交付物
- 小节之间有逻辑递进

### 3. 视频脚本
单个视频15-20分钟，约3000-4000字口播稿。

# [视频标题]

## 开场（30秒）
[开场白，引出主题]

## 第一部分：[小标题]（x分钟）
[完整口播文字，口语化表达]

## 第二部分：[小标题]（x分钟）
[完整口播文字]

...

## 总结（1分钟）
[回顾要点，引导下一讲或行动]

---
预计时长：xx分钟
配套PPT页数：xx页

### 4. PPT生成
使用 pptx skill 生成简洁风格的PPT。

PPT结构对应视频脚本：
- 封面页：课程名+章节标题
- 目录页：本讲内容概览
- 内容页：每个要点1-2页，大字+关键词
- 案例页：案例标题+五要素摘要
- 总结页：本讲要点回顾
- 尾页：下讲预告或联系方式

每页原则：
- 标题不超过10字
- 正文要点不超过5条
- 每条不超过15字
- 留白充足，不堆砌

## 工作流程

### 收到课程制作需求时

1. **确认课程定位**
   - 入门/进阶/垂直？
   - 目标受众是谁？
   - 预期定价区间？

2. **确认内容范围**
   - 是整门课程还是单个模块/章节？
   - 用户是否提供了素材（工作总结、案例、模板）？

3. **确认输出格式**
   - 文字内容？
   - 视频脚本？
   - PPT？
   - 宣传文案？
   - 以上全部？

4. **执行生成**
   - 优先生成文字内容
   - 基于文字内容生成视频脚本
   - 基于视频脚本生成PPT
   - 宣传文案独立生成

5. **标记待审核内容**
   - AI生成的案例标记【待审核：AI生成】
   - 不确定的观点标记【待确认】

## 质量检查清单

生成内容前自检：

- [ ] 是否有具体公司名/项目代号？→ 替换为模糊描述
- [ ] 观点是否有案例或行业框架支撑？→ 无支撑则补充或标记
- [ ] 案例是否包含完整五要素？→ 缺失则补全
- [ ] 交付物是否明确列出？→ 每章必须有
- [ ] 文案是否符合Hao的调性？→ 真实直白、不说空话
- [ ] 时长/字数是否达标？→ 视频脚本3000-4000字
