# 已有课程大纲参考

## 入门课：《游戏项目管理14讲》

**定位**：0-1年新人，建立游戏PM的系统认知
**定价**：698元
**形式**：B站视频课程

### 大纲结构

**常识篇｜建立基础认知**
- 游戏PM的项目管理基础
- 项目管理五大过程组

**实战篇｜贯穿研发全流程**
- 流程制定：研发阶段与线上运营的流程设计
- 版本管理：从规划到发布的完整闭环
- 制定计划：里程碑拆解与周版本迭代
- 过程管理：汇报、风险管控与数据监控
- 范围管理：需求分析、定义、控制与验收
- 质量管理：设计评审与研发质量把控
- 风险管理：识别、评估与应对策略
- 数据分析：用数据驱动决策
- 复盘：让团队持续进化的方法

**求职篇｜拿到心仪offer**
- 游戏PM岗位JD拆解
- 简历怎么写
- 高频面试问题解析

**加更彩蛋**
- 转行游戏PM路上的踩坑经验

## 进阶课：《游戏项目管理进阶：从执行者到架构师》

**定位**：1-3年PM，建立系统性管理能力

理解游戏研发的本质规律
- 游戏研发为什么特别难管

- 不同阶段的管理重点
- 不同品类的管理差异
- 外包管理专题

在问题暴露之前识别和干预
- 风险的本质
- 先行指标vs滞后指标
- 构建预警体系
- 干预的时机与方式
- 里程碑前的风险管理
- 案例研究
- 实战工作坊

**第三模块：跨职能翻译（6章）**
成为策划、程序、美术之间的协议层
- 三种职能的思维差异
- 翻译的四种核心技术
- 建立团队共同语言
- 高难度沟通场景处理
- 案例研究
- 实战工作坊

**第四模块：体系化设计（8章）**
构建能够自运转的研发引擎
- 从依赖个人到依赖体系
- 需求流转体系设计
- 进度管理体系设计
- 质量保障体系设计
- 沟通协作体系设计
- 案例研究
- 实战工作坊

**第五模块：进阶话题（6章）**
应对更高阶的挑战
- 团队扩张期的管理
- 向上管理
- PM的职业发展路径
- 综合案例
- 高级工作坊

### 交付物清单
- 35+模板（需求/进度/质量/风险/沟通/外包/团队）

## 垂直课示例：《非美术背景PM的美术管理生存指南》

**定位**：产品PM视角的美术管理
**目标用户**：非美术背景的PM

### 大纲结构

**引言：重新定义你的角色**
你不是来"懂美术"的，你是来"管美术"的
- 翻译官：把策划需求翻译成美术能执行的规格
- 质量守门人：建立"对不对"的判断标准
- 资源调度者：在看不懂细节时判断进度健康度

**阶段A：建立判断力基座**
- 理解美术工作流的本质
- 建立"进度健康度"判断模型
- 需求文档的"美术友好度"自检清单

**阶段B：三个核心战场**
- 场景1：外包管理
- 场景2：内部协作（策划与美术的冲突调解）
- 场景3：进度与里程碑

**阶段A'：进阶架构（可选）**
- 美术资源规划与预算
- 风格一致性管理
- 技术美术协作

---

## 大纲设计原则

1. **模块化**：每个模块有明确的能力目标
2. **递进式**：从认知到方法到实战
3. **交付物导向**：每章明确列出可带走的东西
4. **案例驱动**：理论必须有案例支撑
5. **适配定价**：内容深度匹配价格预期
