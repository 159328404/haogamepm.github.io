# 标题和Show Notes模板

## 标题格式

### 主标题结构

[核心话题/事件]：[独特视角或价值点]｜油管解读

### 标题示例

- DeepSeek元旦论文：动了Transformer十年没人敢动的地基｜油管解读
- Sam Altman谈OpenAI战略：最好的模型、产品、基础设施，三个都要｜油管解读
- Ilya离开OpenAI后首次公开发言：超级智能的对齐问题怎么解｜油管解读

### 标题原则

1. 不用"震惊"、"必看"等标题党词汇
2. 包含嘉宾名或事件名，增加辨识度
3. 后缀固定为"｜油管解读"
4. 控制在30字以内
