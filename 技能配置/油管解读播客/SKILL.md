# 油管解读播客技能

这是Hao专属的播客脚本生成技能，用于将YouTube英文长视频转换为中文精读播客。

## 节目定位

- **节目名称**：游戏PM笔记 - 油管解读系列
- **内容形式**：中文精读播客（10-20分钟）
- **内容来源**：YouTube高质量英文长视频（Lex Fridman、Dwarkesh Patel等）
- **差异化**：结尾加入游戏行业/项目管理视角的个人点评

## 工作流程

### 第一步：获取视频内容

1. 使用web_fetch获取YouTube视频页面
2. 使用web_search搜索视频的访谈摘要、文字稿或相关报道
3. 如有必要，搜索被访者的相关背景资料

### 第二步：生成播客脚本

按以下结构输出脚本，参考references/script-template.md：

**开场（1-2分钟）**
- 介绍访谈背景、嘉宾、节目来源
- 说明这期内容的核心价值和为什么值得听

**正文（8-15分钟）**
- 按主题拆解，每个主题一个小节
- 用"第一部分"、"第二部分"等口语化分段
- 每个观点用小白友好的方式解释

**游戏行业/PM启示（2-3分钟）**
- 提炼3-4个对游戏行业或项目管理的启发
- 与Hao的工作场景建立具体关联

**结语（30秒）**
- 简短总结
- "下期见"收尾

### 第三步：生成标题和Show Notes

参考references/shownotes-template.md生成配套内容。

## 脚本风格规范

### 必须遵守

1. **小白友好**：用日常比喻解释技术概念（如"单车道扩成多车道"、"给矩阵套数学护栏"）
2. **客观平静**：不用主观评价性语气词，用事实陈述
3. **口语化**：适合直接朗读，用"第一部分"而非"---"分隔
4. **无格式符号**：不用markdown加粗、分隔线，脚本应能直接转语音

### 禁止使用的表达

- 主观评价：~~"很有意思"、"特别重要"、"说得很好"、"问了一个很直接的问题"~~
- 书面语：~~"翻译一下"、"信息密度很高"~~
- AI味口头禅：~~"值得关注的是"、"让我们来看看"~~

### 推荐使用的表达

- 引用时标注来源："Altman认为..."、"知乎上有个评价..."
- 转述而非评价："他的观点是..."、"这里的逻辑是..."
- 用比喻替代术语："像单车道扩成多车道"
