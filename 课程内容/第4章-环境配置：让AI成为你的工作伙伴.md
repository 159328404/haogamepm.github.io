# 第4章：环境配置：让AI成为你的工作伙伴

## 引言

上周和一位PM朋友聊天，他说："我知道AI能帮我写文档、整理会议纪要，但我更想知道AI能不能帮我写代码、帮我做数据分析、帮我自动化工作流程。"

这个问题很关键。Chatbot（聊天机器人）只能帮你处理文本，但**AI开发工具（AI Agent）可以帮你写代码、执行任务、自动化工作流**。这才是AI在PM工作中的真正价值。

这一章，我们要解决的就是这个问题。我们会从游戏PM的实际需求出发，帮你选择适合的AI开发工具，帮你配置工作环境，让AI成为你的得力助手。

这不是理论课，而是实战课。我们会用具体的操作步骤，让你看到如何从零开始配置AI开发环境，如何使用AI Agent完成实际工作。

**重要说明：PM使用AI工具的边界**

PM学习使用AI开发工具，是为了**辅助本职工作**，而不是替代技术岗位。具体来说：

- **PM应该用AI做的**：分析项目进度数据、生成风险报告、自动化重复性的PM工作（如周报生成、数据汇总）
- **PM不应该用AI做的**：替程序写游戏逻辑代码、替美术修图、替策划设计玩法
- **关键原则**：AI工具是放大PM能力的杠杆，不是让PM越界干别人的活

## 4.1 Chatbot vs AI Agent：理解两者的区别

在深入AI开发工具之前，我们先搞清楚Chatbot和AI Agent的区别。

### 4.1.1 Chatbot：文本处理工具

**Chatbot的特点：**
- **输入输出**：文本输入，文本输出
- **能力范围**：理解文本、生成文本、回答问题
- **工作方式**：一问一答，需要人工操作
- **典型场景**：会议纪要整理、文档生成、问答咨询

**主流Chatbot工具：**

**ChatGPT**
- 优势：中文能力强，长文本处理强，迭代优化能力强
- 劣势：需要科学上网，需要付费，数据存储在海外
- 适用场景：处理复杂的中文内容，处理长文本，迭代优化

**豆包（字节跳动）**
- 优势：国内可用，免费，数据存储在国内
- 劣势：长文本处理能力较弱，迭代优化能力较弱
- 适用场景：公司要求使用国内工具，预算有限

**Kimi（月之暗面）**
- 优势：长文本处理能力强（200K上下文），国内可用，免费版功能也较强
- 劣势：中文能力略弱，迭代优化能力较弱
- 适用场景：需要处理超长文本，国内环境，无法使用ChatGPT

**Chatbot的局限性：**
- 只能处理文本，不能执行代码
- 需要人工操作，无法自动化
- 无法操作外部系统，无法自动化工作流

### 4.1.2 AI Agent：代码执行工具

**AI Agent的特点：**
- **输入输出**：自然语言输入，代码执行输出
- **能力范围**：理解需求、生成代码、执行任务、自动化工作流
- **工作方式**：自主执行，可以自动化
- **典型场景**：代码生成、数据分析、自动化脚本、工作流自动化

**AI Agent的核心能力：**
1. **代码生成**：根据需求生成代码
2. **代码执行**：执行生成的代码，查看结果
3. **多文件编辑**：同时编辑多个文件
4. **自动化工作流**：自主完成整个任务流程

**AI Agent的价值：**
- 可以执行代码，不只是生成文本
- 可以自动化工作流，不需要人工操作
- 可以操作外部系统，可以自动化整个流程

### 4.1.3 为什么PM需要AI Agent

**PM的核心痛点：**
- **数据分析**：需要写SQL、Python脚本分析数据
- **自动化脚本**：需要写脚本自动化重复性工作
- **工作流自动化**：需要自动化整个工作流程
- **工具开发**：需要开发小工具提升效率

**Chatbot无法解决：**
- 只能生成代码，不能执行
- 需要人工复制粘贴，效率低
- 无法自动化，需要人工操作

**AI Agent可以解决：**
- 可以生成代码，也可以执行
- 可以自动化整个流程
- 可以操作外部系统，可以自动化工作流

**关键洞察：**

Chatbot适合文本处理，AI Agent适合代码执行和自动化。**对于PM来说，AI Agent的价值更大**，因为它可以帮你写代码、执行任务、自动化工作流。

## 4.3 Cursor详细介绍：核心工具

选择了Cursor，接下来要深入了解Cursor的功能和使用方法。

### 4.3.1 Cursor是什么

**Cursor的定义：**
Cursor是一个AI驱动的代码编辑器，基于VS Code构建，集成了强大的AI能力。

**Cursor的核心功能：**
1. **代码生成**：根据自然语言描述生成代码
2. **代码执行**：在IDE中直接执行代码
3. **多文件编辑**：同时编辑多个文件
4. **自动化工作流**：支持Agent模式，自主完成整个任务
5. **智能补全**：根据上下文智能补全代码

**Cursor的优势：**
- 基于VS Code，熟悉VS Code的用户可以快速上手
- 集成AI能力，不需要切换工具
- 支持多种编程语言（Python、JavaScript、SQL等）
- 支持多种AI模型（GPT-4、Claude等主流模型）

### 4.3.2 Cursor的核心功能

**功能1：Composer（代码生成）**

**什么是Composer：**
Composer是Cursor的核心功能，可以根据自然语言描述生成代码。

**如何使用Composer：**
1. 打开Composer：`Cmd+I`（macOS）或`Ctrl+I`（Windows/Linux）
2. 描述需求：用自然语言描述你要做什么
3. 生成代码：AI生成代码，你可以查看和编辑
4. 应用更改：选择接受或拒绝更改

**Composer的优势：**
- 支持多文件编辑，可以同时编辑多个文件
- 支持@mention，可以引用文件、文件夹、文档
- 支持Agent模式，可以自主完成整个任务

**功能2：Chat（代码问答）**

**什么是Chat：**
Chat是Cursor的问答功能，可以回答代码相关问题。

**如何使用Chat：**
1. 打开Chat：`Cmd+L`（macOS）或`Ctrl+L`（Windows/Linux）
2. 提问：问代码相关问题
3. 获取答案：AI回答你的问题

**Chat的优势：**
- 可以引用代码文件，提供上下文
- 可以回答代码问题，提供建议
- 可以解释代码，帮助理解

**功能3：Agent Mode（自动化模式）**

**什么是Agent Mode：**
Agent Mode是Cursor的自动化模式，可以自主完成整个任务。

**如何使用Agent Mode：**
1. 打开Composer：`Cmd+I`（macOS）或`Ctrl+I`（Windows/Linux）
2. 切换到Agent Mode：`Cmd+.`（macOS）或`Ctrl+.`（Windows/Linux）
3. 描述任务：用自然语言描述你要完成的任务
4. 自主执行：AI自主创建或修改文件，执行终端命令，直到任务完成

**Agent Mode的优势：**
- 可以自主完成整个任务，不需要人工干预
- 可以创建或修改多个文件
- 可以执行终端命令
- 可以持续执行，直到任务完成

**功能4：@mention（上下文引用）**

**什么是@mention：**
@mention是Cursor的上下文引用功能，可以引用文件、文件夹、文档。

**如何使用@mention：**
1. 在Composer或Chat中输入`@`
2. 选择要引用的内容：
   - `@file`：引用文件
   - `@folder`：引用文件夹
   - `@Docs`：引用文档
   - `@Web`：执行网络搜索
3. AI会使用引用的内容作为上下文

**@mention的优势：**
- 可以提供明确的上下文，提高AI理解准确性
- 可以引用多个文件，提供完整的项目上下文
- 可以引用文档，提供项目规范和要求

### 4.3.3 Cursor的快捷键

**常用快捷键：**

**macOS：**
- `Cmd+I`：打开Composer（单文件编辑）
- `Cmd+Shift+I`：打开Composer（多文件编辑）
- `Cmd+L`：打开Chat
- `Cmd+.`：切换Agent Mode
- `Cmd+K`：快速编辑（选中代码后）

**Windows/Linux：**
- `Ctrl+I`：打开Composer（单文件编辑）
- `Ctrl+Shift+I`：打开Composer（多文件编辑）
- `Ctrl+L`：打开Chat
- `Ctrl+.`：切换Agent Mode
- `Ctrl+K`：快速编辑（选中代码后）

**快捷键使用建议：**
- 熟悉快捷键，提高效率
- 根据习惯自定义快捷键
- 定期练习，形成肌肉记忆

## 4.4 Cursor的AI模型：强大的AI引擎

> **注意**：Cursor支持多种AI模型（如GPT-4、Claude、以及Cursor自研模型），且模型能力持续更新。以下介绍的是AI模型在Cursor中的通用能力，具体参数请以官方最新说明为准。

### 4.4.1 Cursor AI模型的核心能力

**AI模型在Cursor中的特点：**
- **处理速度快**：适合快速迭代，多次修改代码
- **多文件编辑**：可以同时编辑多个文件

- 上下文理解能力强，意味着AI能理解你的项目背景
- 代码质量高，意味着生成的脚本可以直接使用，不用懂代码也能跑起来

### 4.4.2 AI模型的核心能力详解

**能力1：快速迭代**

**特点：**
- 处理速度快，响应及时
- 适合快速反馈循环
- 可以连续多个编码会话

**适用场景：**
- 需要快速迭代，多次修改代码
- 需要快速反馈，查看结果

**能力2：多文件编辑**

**特点：**
- 可以同时编辑多个文件

- 可以保持代码一致性

**适用场景：**
- 需要重构代码，涉及多个文件
- 需要实现大型功能，涉及多个文件
- 需要保持代码一致性

**能力3：上下文理解**

**特点：**
- 可以理解整个项目的上下文
- 可以理解文件之间的关系
- 可以理解代码的意图

**适用场景：**
- 需要理解项目结构
- 需要理解代码意图
- 需要保持代码一致性

**能力4：代码质量**

**特点：**
- 生成的代码质量高
- 符合最佳实践
- 可以自动修复lint错误

**适用场景：**
- 需要生成高质量代码
- 需要符合最佳实践
- 需要自动修复lint错误

### 4.4.3 如何使用Cursor的AI能力

**步骤1：打开Composer**

1. 打开Cursor
2. 按`Cmd+I`（macOS）或`Ctrl+I`（Windows/Linux）
3. Composer窗口打开

**步骤2：描述需求**

1. 在Composer中输入自然语言描述
2. 使用@mention引用相关文件
3. 描述要完成的任务

**示例：**
```
创建一个Python脚本，分析Jira导出的Excel数据，识别延期风险。

@file jira_data.xlsx
@folder project_background

要求：
1. 读取Excel数据
2. 计算任务完成率
3. 识别延期风险（完成率低于80%）
4. 生成风险报告
```

**步骤3：查看和编辑**

1. AI生成代码，显示在Composer中
2. 查看代码，检查是否符合要求
3. 可以编辑代码，调整细节

**步骤4：应用更改**

1. 点击"Accept"接受更改
2. 或点击"Reject"拒绝更改
3. 可以部分接受，部分拒绝

**步骤5：迭代优化**

1. 如果代码不符合要求，继续描述需求
2. AI会根据反馈调整代码
3. 持续迭代，直到满意

## 4.5 Cursor配置和使用：从零到一

了解了Cursor的功能和AI模型能力，接下来要配置和使用Cursor。

### 4.5.1 安装和配置

**步骤1：下载和安装**

1. 访问Cursor官网：https://cursor.sh
2. 下载Cursor（支持macOS、Windows、Linux）
   - macOS：下载.dmg文件，双击安装
   - Windows：下载.exe文件，双击安装
   - Linux：下载.deb或.rpm文件，按照系统提示安装
3. 安装Cursor（按照安装向导，和安装普通软件一样）

**说明**：安装Cursor就像安装普通软件一样，不需要技术背景。如果遇到问题，可以告诉AI："帮我安装Cursor"，AI会指导你。

**步骤2：注册和登录**

1. 打开Cursor（双击图标）
2. 点击"Sign up"注册账号（如果没有账号）
3. 使用邮箱注册，验证邮箱（会收到验证邮件，点击链接验证）
4. 登录Cursor（使用注册的邮箱和密码）

**说明**：注册和登录就像注册普通网站一样，不需要技术背景。如果遇到问题，可以告诉AI："帮我注册Cursor账号"，AI会指导你。

**步骤3：订阅和配置**

1. 点击"Upgrade"订阅（$20/月，约140元/月）
2. 选择订阅计划（选择Plus版本）
3. 完成支付（支持信用卡、PayPal等）
4. 配置AI模型（根据订阅版本选择最佳模型）

**说明**：订阅需要付费，但这是值得的投资。如果预算有限，可以先试用免费版，再决定是否订阅。如果遇到问题，可以告诉AI："帮我订阅Cursor Plus"，AI会指导你。

**步骤4：基础设置**

1. 打开设置：`Cmd+,`（macOS）或`Ctrl+,`（Windows/Linux）
2. 配置AI模型：
   - 选择推荐的默认模型（Cursor会根据订阅版本提供最佳选择）
   - 配置其他AI模型（GPT-4、Claude等）
3. 配置快捷键：

## 实用Prompts

这一章我们学习了如何配置AI开发环境。下面是一些实用的prompts，帮你在Cursor中快速完成数据分析和项目创建。这些Prompt也适用于其他AI开发工具（如Trae、Windsurf等），只需调整@mention语法即可。

### Prompt 1：创建数据分析脚本

```
你是一名游戏项目经理，请帮我创建一个Python脚本，分析项目数据。

【3C卡定义】
Context：我需要分析[数据类型]数据，生成分析报告，用于[使用场景]
Components：脚本需要包含数据读取、指标计算、异常识别、报告生成四个模块
Criteria：脚本要能正确运行，报告格式清晰，数据准确

【Cursor上下文引用】
@file [数据文件路径，如：data/jira_export.xlsx]
@file [项目背景文档，如：docs/project_background.md]

【数据说明】
- 数据来源：[数据从哪里导出的，如Jira、后台等]
- 数据格式：[Excel/CSV/JSON]
- 数据字段：[列出主要字段，如：任务ID、状态、负责人、截止日期等]
- 数据量：[大约多少行数据]

【分析需求】
1. 关键指标计算：
   - [指标1]：[计算方式，如：任务完成率 = 已完成任务数 / 总任务数]
   - [指标2]：[计算方式]
   - [指标3]：[计算方式]

2. 异常数据识别：
   - [异常类型1]：[判断条件，如：延期任务 = 实际完成日期 > 截止日期]
   - [异常类型2]：[判断条件]

3. 输出要求：
   - 输出格式：Markdown
   - 输出文件：[输出文件路径，如：output/analysis_report.md]
   - 报告结构：[概览 → 关键指标 → 异常数据 → 建议]

【实现步骤】
请按照以下步骤实现：
1. 先创建基础脚本，读取数据文件
2. 添加数据清洗函数，处理空值和异常值
3. 添加指标计算函数，计算关键指标
4. 添加异常识别函数，识别异常数据
5. 添加报告生成函数，生成Markdown报告
6. 添加主函数，串联所有步骤
7. 运行测试，确保脚本正常工作
```

**使用说明：**
- 在Cursor中使用时，用`@file`引用实际的数据文件
- 如果使用其他AI工具，可以直接粘贴数据或描述数据结构
- 脚本生成后，建议先用小数据集测试，确认无误后再处理完整数据
- 这个Prompt适合分析Jira数据、后台数据、问卷数据等
